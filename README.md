TrackerBean - README
Overview
TrackerBean is a comprehensive tracking application designed to help users monitor and manage various aspects of their daily activities and data. Built with modern web technologies, this app provides an intuitive interface for tracking, organizing, and analyzing information efficiently.

Features
Activity Tracking: Monitor and log your daily activities
Data Organization: Organize tracked information in a structured manner
Analytics & Insights: Gain insights from your tracked data
User-Friendly Interface: Clean and intuitive UI for easy navigation
Real-time Updates: See changes reflected immediately

Installation
1.) Download installer exe from GitHub
2.) Open the installation exe
3.) Follow the on-screen setup wizard to get started
4.) Begin tracking your activities

Usage
1.) Launch the application
2.) Link your steam or click to add steam account (if you have steam already)
3.) Start tracking your activities
4.) View analytics and insights from your data

For issues or questions, please open an issue on the GitHub Issues page.
